# 4-Week Gym Program

## Summary

- Schedule: Monday, Tuesday, Thursday, Saturday
- Inside-gym cap: 40 minutes
- Walking: 20 minutes in + 20 minutes out, counted as warm-up and cooldown
- Strength days: Monday and Thursday, effort 6-7/10
- Easy days: Tuesday and Saturday, effort 4-5/10
- Equipment: machines + cables
- Month 1 exclusions: deadlifts, barbell squats, overhead press, crunches, sit-ups, twisting core machines, heavy carries, running

## Session Rules

- Start with a 1-minute pain check: lumbar, neck, radiation.
- Keep every set 2-3 reps away from failure.
- Use controlled tempo: about 2 seconds down, 1 second up.
- Rest 75-90 seconds after main machine lifts.
- Rest 45-60 seconds after smaller, cable, and core work.
- Rest 30 seconds during mobility and prep.
- If form changes, stop the set.

| Order | Exercise | Sets x Reps | Rest | Effort |
|---:|---|---:|---:|---:|
| 1 | Dead bug | 2 x 6/side | 30s | Easy |
| 2 | Bird dog | 2 x 6/side | 30s | Easy |
| 3 | Leg press | 2 x 10 | 90s | 6-7/10 |
| 4 | Seated row or chest-supported row | 3 x 10 | 75s | 6-7/10 |

Notes:

- Leg press: back stays fully supported; do not go so deep that hips tuck under.
- Row: chest-supported is preferred if available.
- Chest press: keep shoulders down; no neck shrugging.

## Progression

Week 1:

- Learn the setup, machine positions, and pain response.
- Use easy weights.

Week 2:

- Keep the same weights.
- Make reps cleaner and smoother.

Week 3:

- If pain is stable, add 1 set only to either Monday leg press or Monday chest press.
- Do not add sets to both.

Week 4:

- If all sets feel controlled, increase weight by the smallest available machine jump on 1-2 main exercises.
- Keep Tuesday and Saturday easy.

If next-morning pain is worse:

- Reduce the next matching session's weights by 20%.
- Keep only 2 sets per exercise.
- Keep effort at 4-5/10 until symptoms return to baseline.

## Fallback Sessions

### Pain Above 3/10 or Radiating Symptoms

Do this only:

1. Dead bug - 2 x 6/side
2. Bird dog - 2 x 6/side
3. Cable Pallof press - 2 x 8/side, light
4. Easy bike or treadmill walk - 8-10 min

Then leave.

### Only 25 Minutes Available

Do this:

1. Dead bug - 1 x 6/side
2. Bird dog - 1 x 6/side
3. Leg press - 2 x 10
4. Row - 2 x 10
5. Machine chest press - 2 x 10
6. Pallof press - 1 x 8/side

### Machine Busy

- Do the next exercise and return later.
- Do not replace a planned machine with barbell/free-weight versions in month 1.
